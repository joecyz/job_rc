Backend API untuk Website Job Recruitment

## Tech Stack

- Python 3.14
- Django
- Django REST Framework
- MySQL
- JWT Authentication

## Features

- Authentication
- Applicant Profile
- Education
- Document Upload
- Job Management
- Job Application
- Event Management
- FAQ
